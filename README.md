# S&P 500 Stock Trend Analysis

## 📊 Overview
This project analyzes historical stock data from S&P 500 companies using Python. The goal was to identify trends, compare company performance, and evaluate overall returns across multiple stocks.

---

## 🎯 Objectives
- Analyze stock price trends over time
- Compare performance between companies
- Calculate percentage returns
- Identify top-performing stocks

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

---

## 🧹 Data Cleaning
- Converted `date` column to datetime format
- Handled missing values by removing incomplete rows
- Sorted data by company and date to ensure accurate analysis

---
## 📈 Analysis Performed
- Time-series visualization of individual stocks
- Comparison of multiple companies (e.g., AAPL vs AAL)
- Normalized stock prices for fair comparison
- Calculated percentage returns for all companies
- Identified top-performing stocks

---

## 🔍 Key Findings
- NVIDIA (~1749%) and Netflix (~923%) were the top-performing stocks
- Technology companies dominated overall growth
- Some stocks showed high volatility, while others exhibited stable, consistent growth
